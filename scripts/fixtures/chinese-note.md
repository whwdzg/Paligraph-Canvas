# 安静的创作空间

一个好的笔记工具，应该安静地退到思绪背后。Paligraph 从一张纸、几支笔开始，没有多余的东西争夺注意力。

## 页边笔记

界面借鉴了三个想法：

- **Fluent** 的材质与层级，在 Windows 上自然熟悉。
- 一张有结构但不喧哗的网格纸。
- 像真正的墨水一样，带一点压力与不完美。

> 最好的工具，是你忘记自己正在使用的工具。

你可以直接在这张阅读卡片上绘画、圈出句子，或者在旁边补一张草图。
